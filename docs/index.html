ℹ️ Информация по установке:

  1. Официальный Telegram удалять НЕ нужно: Garantgram ставится как отдельное независимое приложение.
  2. После нажатия «Установить» подтвердите установку в системном окне iOS.
  3. Перейдите в Настройки -> Основные -> VPN и управление устройством и нажмите «Доверять».
  4. Если система потребует Режим разработчика: Настройки -> Конфиденциальность и безопасность -> Режим разработчика -> Вкл.
