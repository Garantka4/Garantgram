# ✈️ Garantgram for iOS

> **Garantgram** — быстрый, безопасный и модифицированный клиент Telegram для iPhone и iPad с полным Ghost-режимом (невидимкой) и вырезанной рекламой.

---

## 🌟 Ключевые возможности

### 👻 Полный Ghost Mode (Невидимка)
* **Скрытое чтение**: собеседники не видят, что вы прочитали сообщения (у них всегда остаётся одна галочка).
* **Скрытый тайпинг**: статус «Печатает...», «Записывает голосовое...» и «Отправляет медиа...» не транслируется в сеть.
* **Скрытые Stories**: просмотр любых историй пользователей и каналов без попадания в список просмотров (полный Stealth-режим).

### 🚫 Полное отсутствие рекламы
* Спонсорские и рекламные сообщения Telegram в каналах полностью заблокированы на уровне сетевого ядра (`TelegramCore`).
* Никаких всплывающих баннеров и навязчивых промо-блоков.

### 🛡 Приватность и безопасность
* Все данные и ключи шифрования передаются напрямую через официальные сервера Telegram MTProto.
* Отсутствие сторонних трекеров и аналитики.

## 🚀 Как установить на iPhone / iPad

Приложение собирается в облаке через **GitHub Actions** и выдаёт готовый файл **`Garantgram.ipa`**.

### 1. Сборка `.ipa` (в 1 клик):
1. Перейдите во вкладку **[Actions](../../actions)** в этом репозитории.
2. Выберите слева воркфлоу **«Build Garantgram iOS»**.
3. Нажмите кнопку **«Run workflow»** справа.
4. Дождитесь окончания сборки (в среднем ~20–30 минут).
5. Готовый файл **`Garantgram.ipa`** появится в разделе **[Releases](../../releases)** или во вкладке артефактов Actions.

### 2. Способы установки `.ipa`:
* **TrollStore** (для iOS с поддержкой CoreTrust): просто откройте скачанный `.ipa` через TrollStore — подпись будет вечной.
* **AltStore / SideStore**: установите через ПК с использованием личного Apple ID (бесплатно, переподпись раз в 7 дней).
* **Sideloadly**: быстрая установка через кабель с Windows/Mac.
* **Scarlet / Esign**: прямая установка сертификатом на устройстве.

## ⚙️ Стек технологий
* **Язык**: Swift / Objective-C / C++
* **Сборочная система**: Bazel
* **Интерфейс**: Telegram UI Core (AsyncDisplayKit / Texture)
* **Сеть**: MTProtoKit Engine
